# Examples

Sample outputs from the skill, for reference — not inputs the method reads.

## `lexical-targets-T1-T4.png`

Four isolated lexical targets (T1–T4) produced during the Stage A / lexical-blind
probe, plotted as narrowband spectrograms on the recording's global timeline:

- **T1** — 51.27–52.97 s
- **T2** — 199.75–201.50 s
- **T3** — 239.75–242.25 s
- **T4** — 258.30–259.60 s

Each panel is titled `blind: no ASR / no transcript`, reflecting the skill's iron
rule — these targets were located from acoustic structure alone, before any speech
recognition or transcript was consulted. The stable target IDs come from
`scripts/lexical_targets.py`.
